# Audio

音声素材を置く。

## サブフォルダ

| パス | 置くもの | 推奨形式 |
|------|----------|----------|
| `music/` | BGM（ループ想定） | OGG / MP3 |
| `sfx/` | 効果音（クリック、サイコロ、カードなど） | WAV / OGG |

## 置かないもの

- ボイス（必要になったら `voice/` を追加）
- 画像・フォント

## 命名例

- `music/bgm_title_loop.ogg`
- `sfx/sfx_dice_roll.ogg`
- `sfx/sfx_card_flip.wav`

## 参照例

`assets/audio/sfx/sfx_dice_roll.ogg`
