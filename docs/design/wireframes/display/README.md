## 開始前 PNG（①〜⑥）と設計フェーズ

| PNG | 設計上 | スマホ側の主な操作 |
|-----|--------|-------------------|
| ① 参加受付 | lobby | QRスキャン・名前 |
| ② マ券購入 | betting（毎レース） | ドラフト・セーフ／リスキー |
| ③ カード選択 | card-seed | 手札1枚の仕込み |
| ④ 場のカード | setup-cards | （参照） |
| ⑤ カード決定 | card-seed 完了・デッキ組成 | — |
| ⑥ 準備完了 | レース開始直前 | — |

④の公開はセットアップ／ベット前が原作に近い。PNGの並びはビジュアル参考とし、進行順は overview の正規フローに従う。

| 内容 | 設計上 |
