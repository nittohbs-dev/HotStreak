# 会場ディスプレイ（Pygame）

リポジトリのルートで `./play.sh --windowed` を実行します。
同期サーバーと会場アプリが同時に起動し、QR受付から3レース終了までつながります。
詳細な遊び方とLAN接続はルートの [`README.md`](../../README.md) を参照してください。

## 操作

- QR受付: 同じWi-Fiのスマホで参加。全員の参加を確認し、3人以上でEnterを押して開始。
- 公開カード: 左右キーで第1レースのドラフト先頭を選び、Enterでマ券へ。
- マ券: 全員2枚（第3レースはダブル指定も）そろってからEnter。
- 仕込み: 全員1枚そろってからEnter。
- レース: Enterで1枚ずつめくる。
- 結果: Enterで次レース、第3レースの後は受付へ。
- Esc／ウィンドウ閉じ: アプリ終了。同時起動したサーバーも終了。

通信は別スレッドの `connection.py` が担当し、Pygame描画はメインスレッドのみで行います。
Enterはサーバーの応答で確定します。切断中に押したEnterを後で実行することはありません。

## 起動オプション

```sh
./play.sh --windowed --public-host 192.168.1.10 --port 8000
./play.sh --windowed --font /path/to/japanese.ttf
# 外部で起動済みのサーバーを使う場合（会場PC上のループバックへ接続）
./play.sh --windowed --server http://127.0.0.1:8000
```

Python 3.11以上。`requirements.txt` に同期側と画面側の依存をまとめています。
Macではヒラギノ、Windowsでは游ゴシック／メイリオ、LinuxではNoto Sans CJK等を使えます。
1280×720の論理解像度で描画し、ウィンドウサイズに合わせて拡縮します。

## デモとの違い

`app.py` が実プレイの入口です。`screens/*.py` の単独起動は以前の画面確認用デモとして残しています。
`BETTING_MOCK.md`、`CARD_SEED_MOCK.md`、`RACE_MOCK.md`、`PAYOUT_MOCK.md` はそのデモの説明です。
旧 `setup_cards.py --session` の単独接続は新しい認証・revision付きadvanceに未対応なので、実プレイには使わないでください。

既存の部屋背景、カードアトラス、採用キャラクター、レースの描画を使用しています。
サーバーの位置を画面で補間しますが、手番・札・順位・払戻を画面側では決定しません。

## 検証

```sh
PYTHONPATH=src uv run --python 3.12 --with-requirements requirements.txt --with pytest --with httpx python -m pytest tests/hotstreak_display -q
```

`test_live_game.py` は3人・8人の実スナップショットで全画面を描画します。
QRは生成結果をデコードして参加URLとの一致を確認しています。
実機のスマホWi-Fi・Raspberry Pi・物理ボタンは別途実機確認が必要です。


## 全画面と音声の確認

- `./play.sh` または `./play.sh --fullscreen`: モニターの実解像度で全画面表示。
- `./play.sh --windowed`: 1280×720のウィンドウ表示（サイズ変更可）。
- 表示は16:9を保ち、異なる比率のモニターには余白を付ける。全画面とウィンドウの同時指定は不可。
- BGMが停止した場合は5秒間隔で再開を試みる。再生に失敗している間は画面下に音声の再接続表示が出る。
- 音が聞こえないときは端末の出力先・ミュート・スピーカーを確認する。SDL_AUDIODRIVER=dummyは自動テスト用の無音出力なので、実機起動には指定しない。
- テスト成功やmixerの再生状態だけでは、会場スピーカーから実際に聞こえることの保証にはならない。

## スマホのENTER

最初に参加した人のスマホに、ロビーから総合優勝まで共通のENTERボタンを表示する。進行役は3レース通して固定し、再接続で交代しない。

- レース以外: ENTERで次画面へ（全員の選択完了を待つ）。
- レース中: 短押しで1枚、1秒長押しで自動開始・再開、自動進行中は押下で停止。
- 会場Displayが接続中のときだけレース操作ができる。会場のEnterキーも引き続き使える。
- 次ゲームの参加受付では、最初に参加した人を改めて進行役にする。
