## 命名

| 対象 | 規則 | 例 |
|------|------|-----|
| 機能ID | kebab-case | `user-auth` |
| API-ID | `API-<FEATURE>-<NNN>` | `API-AUTH-001` |
| 画面ID | `SCR-<FEATURE>-<NNN>` | `SCR-AUTH-001` |

## 設計書の更新ルール

- 初回設計: 人間レビュー後に design PR で main へマージ
- 実装中: AI は設計書を自動更新しない
- **軽微な調整**: 人間が依頼した場合、同じ feat PR 内で該当表・行のみ更新（別 PR 不要）
- **大きな変更**: 別 design PR（REQ/API/画面フローの変更）
