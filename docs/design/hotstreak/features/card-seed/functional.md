## ビジネスルール

| BR-ID | ルール | 例外時の振る舞い |
|-------|--------|------------------|
| BR-seed-001 | タイマー遷移なし | 全員揃いまたは Enter |
| BR-seed-002 | 各プレイヤーちょうど1枚仕込み | 未仕込みで advance すると 409 |
| BR-seed-003 | 開始時山＝公開カード＋仕込み＝標準18。組成は仕込み完了時 | 不一致は組成失敗（エラー）。補充続行しない |
| BR-seed-004 | 仕込み札は裏向き（他プレイヤーに中身非公開） | Display も中身非表示 |
| BR-seed-005 | 確定後の仕込み変更は不可 | — |

## 要件

### REQ-seed-001: 仕込み選択

`API-SEED-002` で handCardId を1つ指定する。手札に無い ID は拒否。

### REQ-seed-002: デッキ組成

全員仕込み完了（または Enter 補完後）に公開カード集合と仕込み札を合わせて `RacingDeck` を組む。枚数は 18 − 公開枚数＝参加人数 を前提（setup-cards の人数表と整合）。不一致時は組成失敗（エラー）とし、不足補充で続行しない。

### REQ-seed-003: 同期

`seed.state` で各 player の seeded フラグと deckCount 見込みを配信。手札中身は本人の GET 以外に出さない。

### REQ-seed-004: 遷移

全員 seeded のとき、自動または Enter で `card-seed` → `race`。

### REQ-seed-005: Enter 未仕込み（採用）

1. `API-SEED-003`（advance）は全員 seeded のときのみ成功する。
2. 未仕込みのまま Enter／advance → **409**（欠けた仕込みを自動補完しない）。
3. **force-advance API は設けない**。司会はプレイヤー完了を待つ。
