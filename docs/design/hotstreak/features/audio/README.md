# 会場BGM・効果音

## 概要

会場Displayで、ゲームの表示フェーズに合わせたBGMと効果音を再生する。2026-10-08にユーザーが音付き実動作動画を確認し「それでいいかフローに沿って実装しよう」と承認した構成を正本化する。

## スコープ

| 含む | 含まない |
|------|----------|
| 待機曲「いたずらスウィング」40%、レース曲「Run Amok」50% | 新しい選曲・音量設定画面、Phoneからの再生 |
| 確定・カード公開・一歩・転倒・逆走・開始・ゴール・配当の8種 | ゲームのルール・抽選・進行APIの変更 |
| 既存の会場起動経路での再生、音声障害時の継続、クレジット | 音声のネットワーク配信、DB永続化 |
| 実セッションでの音付き確認動画と再現手順 | ラズパイ実機・会場スピーカーの音量認定 |

## 依存機能

- lobby / setup-cards / betting / card-seed / race / payout の会場表示。
- `live.py` のカード公開・開始カウント・最終カード演出を維持する。従来の `app.py` の起動経路にも同じ音源・音量を適用する。

## 受け入れ条件

- [ ] REQ-audio-001: 承認済み2曲と8種類の効果音が、下記仕様の音量・タイミングで会場から再生される。
- [ ] 同じ通知や描画フレームでBGMを再開始せず、単発効果音を重複させない。
- [ ] 最後のカード演出がある経路では、演出終了までレース曲を維持してから配当へ切り替える。
- [ ] 3レース・ロビー復帰・途中再接続で再生状態が混線しない。
- [ ] 音声デバイスや一部ファイルが利用不能でも、可能な音だけ再生しゲームを継続する。
- [ ] 出典・CC BY 4.0の表示、音付き動画、音声テストが揃う。

## 決定根拠

2026-10-08: 効果音8種類を採用、待機曲は③、レースは①「Run Amok」。BGMが小さいとの指摘を受け、待機20%→40%、レース24%→50%に変更した動画をユーザーが承認。正式実装はこの構成を維持する。
