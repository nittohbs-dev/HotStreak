# レース表示モック（Issue #37）

```sh
python -m pip install -r src/hotstreak_display/requirements.txt
python src/hotstreak_display/screens/race.py --windowed
python src/hotstreak_display/screens/race.py --windowed --effects-demo
python -m unittest discover -s tests/hotstreak_display -p "test_race*.py"
```

Enterで1枚ずつめくる固定シナリオ。長押し・演出中の追加入力は無視する。結果画面のEnterで再開、Escで終了。F1・F2・R操作や常時操作案内は表示しない。`--effects-demo` は追加カード効果8例の自動再生。

右上に今回のカードと効果、左上にゴールした順のアイコン・名前を表示する。海上の4レーン×12列を使用し、初期位置は0始まりの列2。★は列0・5・8とゴール先の12。列2にスタート線があり、後方にも移動できる。山札切れで左3列を短縮し、下に残ったキャラは失格。

全50種類のレースカード定義に対応。移動・負数移動・★・方向転換・転倒・復帰・左右移動・全員移動と復帰を処理する。転倒中は数値・★移動を1マスに制限。左右は向き基準。個別移動の通過・横移動による衝突で停止中キャラが転倒、再転倒で失格。コース外も失格。緑カードは衝突せずゴール直前まで。同時失格は低い同順位。3体が終了したら残る1体の順位を確定する。

採用済み4体の全身透過画像を使用。マムは茶色の巻き髪・白い顔まわり・黄色い服。走行2フレーム、向き変更、転倒と復帰を描画する。画像生成の指示は「採用した4体の姿と配色を保つ4列2段の走行素材。文字と背景を除去し、マムの衣装を変更しない」。素材は `assets/images/characters/racers-approved.png`、内蔵画像生成で制作。

通信、無作為の山札・バーン演出、投票・配当、本番画面間遷移は未実装。山札再準備は固定表示。このモックのみでIssue全体の受け入れ条件を満たすものではない。

左上の確定着順にはゴールと失格の両方を表示する。ゴールは上位から、失格は空いている下位（最初は4位、次は3位）から割り当て、順位（○位）・アイコン・名前のみを表示し、失格・ゴールのラベルは付けない。同時失格は同じ低い着順を使う。
