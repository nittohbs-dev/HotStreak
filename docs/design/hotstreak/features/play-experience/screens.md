# 画面設計: 会場プレイ体験

| SCR-ID | 名前 | 内容 |
|--------|------|------|
| SCR-play-001 | 総合優勝 | 会場は中央の大きな勝者名・所持金。Phoneは配当表を隠し勝者を表示 |
| SCR-play-002 | 進行ボタン | Phone下部、最初の参加者のみ。次画面名と待機理由 |

```mermaid
flowchart LR
  payout[第3レース配当] -->|Enterまたは進行役Phone| champion[総合優勝]
  champion -->|Enterまたは進行役Phone| lobby[参加受付]
```

```text
┌──────────── HOT STREAK ──────────────┐
│                総合優勝              │
│                                      │
│              勝者の名前              │
│                $ 42                  │
│      同点は全員を2列で等しく表示      │
│                                      │
│          ENTER → 参加受付へ           │
└──────────────────────────────────────┘
```

名前は40文字・8人でも枠外へ出さない。Phoneは改行しスクロール可能。
