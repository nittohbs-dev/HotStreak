## SCR-display-005: レース進行

### 目的

バーン、カードめくり、マスコット移動、コース短縮を演出する。レース中にプレイヤー判断は入れない。会場DisplayのEnter短押しで1枚、1秒長押しで自動開始、自動中の押下で停止する。カードと効果の演出完了後に次の1枚を要求する。

### レイアウト

| エリア | 要素 | 動作 |
|--------|------|------|
| 左上 | RACE番号のみ | 進行度バーは表示しない（ユーザー指示） |
| 右上 | 今回のカード | めくりごと更新 |
| 中央 | コース・マスコット4体 | 移動・向き・転倒 |
| 演出 | 3,2,1 / GO / コース短縮 | フェーズ表示 |
| 左上のRACE番号の右隣 | 自動進行状態・Enter案内 | 待機「Enterで1枚 / 1秒長押しで自動開始」、ON「自動進行中 / Enterで一時停止」、停止途中「このカードの演出後に停止 / 1秒長押しで自動再開」、停止済み「一時停止中 / Enterで1枚・1秒長押しで自動再開」 |

通信失敗時は「通信確認中 / 自動進行を停止しました」。最新状態を取得するまでは再開しない。案内は既存カード・履歴・エラー表示と重ならない位置に置く。

### ワイヤー（ASCII）

```
+------------------------------------------+
| START =====o==o====o====o==== GOAL       |
|                      今回のカード         |
|                      [ 対象 +効果 ]       |
|   （コースグリッド／マスコット）          |
+------------------------------------------+
```

マス表現は4レーン×13マス＋GOAL（STARTは3、★は3・8・13）。効果ラベルは manual §6 の種別名。

## 2026-09-21 ビジュアル修正

ゲーム進行画面-ディスプレイ側.pngの海・島・緑の台形コースを採用。上部の進行度バーは不要というユーザー指示により非表示。右上に今回のカードと効果、左上にゴール順のアイコンと名前を表示。従来は操作案内を非表示としていたが、2026-10-08の自動進行変更ではRACE番号の右隣に開始／停止状態とEnter案内を表示する。開始カウントとGOも同じ位置に表示し、中央の開始案内と下部の状態帯は表示しない（2026-10-08ユーザー指定）。室内背景と金枠の共通基準より本画面の指示を優先する。

左上の確定着順にはゴールと失格の両方を表示する。ゴールは上位から、失格は空いている下位（最初は4位、次は3位）から割り当て、順位（○位）・アイコン・名前のみを表示し、失格・ゴールのラベルは付けない。同時失格は同じ低い着順を使う。
