## 要件

### REQ-race-001: バーンと開始

`card-seed` → `race` 入場後、`RaceEngine` がデッキをシャッフルし3枚バーン。Display にカウント／GO を出し、めくりループに入る。

### REQ-race-002: めくりと効果

1枚めくり → 対象マスコットと効果種別を `race.state` で配信 → 位置・向き・転倒等を更新。解決の詳細手順は英語ルール正。設計ペイロードは effectKind（種別名）と要約ラベルまで。

### REQ-race-003: コース短縮

山が尽きたら捨て札をシャッフルして山に戻し、コースを奥／左から短縮。デジタルでは **3マス単位**（12マスの1/4）を削除する想定（ワイヤー観測）。消えたマス上のマスコットは失格。

### REQ-race-004: 終了と遷移

終了条件を満たしたら着順（1〜4）と sideBetOutcome を確定し `race.finished` → フェーズ `payout`。

### REQ-race-005 / 006: Phone 観戦

自分の所持札・balance・プレイヤー順位を常時表示。004b で全員の札一覧。

### REQ-race-007: コース寸法（デジタル）

Course は **4レーン × 12マス**（START〜GOAL）。★は列 3・6・9。座標はレーン index 0..3、進行方向マス 0..11（GOAL 到達でフィニッシュ）。
