## 要件

### REQ-audio-001: 承認済みBGM・効果音を会場表示に同期する

曲と再生範囲:

| 場面 | 音源 | 音量 |
|------|------|------|
| lobby / setup-cards / betting / card-seed / payout | オリジナル③「いたずらスウィング」 | 40% |
| race（開始カウントから最後の演出完了まで） | Kevin MacLeod「Run Amok」 | 50% |

素材は `assets/audio/music/`（BGM）、`assets/audio/sfx/`（効果音）に同梱する。効果音の音量は一歩28%、その他68%。OSや会場アンプの音量はこの割合に含まない。

| 種類 | 発音タイミング |
|------|----------------|
| 確定 | 非レース画面への進行（初回表示と配当以外） |
| カード公開 | 新しいカードの公開開始。公開数とレースを識別して一度 |
| 一歩 | マスコットの表示座標が変化している間。最大約5.6回/秒 |
| 転倒 | マスコットの転倒状態が表示へ反映されたとき。衝突による転倒も含む |
| 逆走 | マスコットの向きの変更が表示へ反映されたとき。復帰で前向きになる場合も含む |
| 開始 | 既存の画面上の3・2・1・GOに同期。開始音をカウント音とGO音に分割して使用 |
| ゴール | 表示上のstatusがgoalに変わったとき。失格をゴール音で扱わない |
| 配当 | 結果画面の初回表示。最終カード演出がある経路では完了を待つ |

音声状態は会場内メモリのみ。通信復帰で同じ状態が届いても音を重複させず、別セッションの同じレース番号は別の開始として扱う。初めから配当画面を受け取った場合は過去のゴール・配当音を再生せず待機曲から始める。終了時はBGMと効果音を停止する。

両会場起動経路で既存の画面遷移・演出時間は変更しない。`live.py` の最後の演出が残る場合はその演出を優先する。`app.py` の即時結果表示経路では、既存の結果画面への切替に合わせて最後のゴール（該当する場合）と配当音を鳴らす。

`Run Amok` は [配布元](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1400024) の [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) を用いる。他の音源は本プロジェクト用に作曲・合成した音源。録画のための依存パッケージはゲーム実行時の必須依存にしない。
