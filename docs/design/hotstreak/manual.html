1. このゲームについて

4体のマスコットがコースを走るレースに、マ券やサイドベットで賭けます。レース前に手札からカードを1枚仕込むと、展開に少しだけ口を出せます。

全3レース。終わったとき所持金がいちばん多いプレイヤーの勝ちです。

デジタル版では、大きな画面（ディスプレイ）でみんなで観戦し、各自のスマホで操作します。

人数の目安は 3〜8人（標準ルール想定）。2人用・大人数用バリアントは今の仕様範囲外です。

2. 用意するもの・役割

ディスプレイ（Raspberry Pi）

QR・公開カード・レース演出・着順など、会場共有の画面。進行用の Enter ボタンもこちら側。

スマホ（各プレイヤー）

参加、マ券の選択、カード仕込み、観戦中の自分情報・配当の確認。

開始時の配布（標準）

  • 所持金 $10
  • 手札 3枚
  • 公開カード（マスコットごとのスターター＋人数に応じた枚数）をディスプレイに表向き表示

3. 進行のしかた（重要）

スマホに制限時間で勝手に次へ進む機能はありません。

トリガー内容
全員揃い その段階で必要な操作を全員が終えたとき（例: 全員が名前確定、全員がマ券2枚取得、全員が仕込み済）
ラズパイ Enter 司会・運営が Enter を押して次の段階へ進める
例外: レースそのもののカードめくり・着順確定は、ルールの計算結果で進みます（タイマーではありません）。配当のあとに次のレースやロビーへ戻るときは、原則 Enter です。

4. 遊び方（1試合の流れ）

全体像

参加→ 公開カード→ マ券→ 仕込み→ レース→ 配当

「マ券 → 仕込み → レース → 配当」を 3回繰り返します。

① 参加（ロビー）

  1. ディスプレイの QR をスマホで読み取る
  2. プレイヤー名を入力して確定する
  3. 全員の名前が揃う、または Enter でセットアップ完了

② 公開カード

これからレースに入りうるカードの一部が、ディスプレイに表向きで並びます。マスコットごとの「気配」を見てから賭けましょう。

③ マ券・サイドベット（スネークドラフト）

  • 各プレイヤーが 2枚取る（マスコットへのマ券、またはサイドベット）
  • 取った直後に表裏を選ぶ: セーフ / リスキー
  • 順番はスネーク（時計回り → 逆順）
  • 第3レースだけ: 自分の2枚のうち 1枚だけ配当をダブルに指定（マイナスも倍。全体×2ではない）

④ カード仕込み

手札から 1枚を選び、レーシングデッキに裏向きで入れます。全員が仕込むか、Enter で次へ。

公開カードと仕込みを合わせて、開始時の山は標準で 18枚になります。

⑤ レース

  1. 山をシャッフルし、上から3枚を捨てる（バーン）「3, 2, 1… GO!」
  2. 1枚ずつめくり、表示どおりマスコットが動く
  3. 山が尽きたらリシャッフルし、コース短縮（奥が消える演出）。短縮で埋まった位置のマスコットは失格
  4. 3体がゴールまたは失格したらレース終了。4体目は残りの着順

⑥ 配当

  • マスコットのマ券: 着順に応じた金額（4着は $0）
  • サイドベット: お題の YES/NO が当たれば配当。リスキー面は外れで損することもある
  • 所持金が足りない損失は払える分まで → 最低 $0

Enter で次のレースへ。レース間ではマ券の返却、新しいサイドベットお題、手札の補充（再び3枚）、コースとマスコットのリセット、ドラフト先頭のローテが行われます。

6. レース中に起きること

めくられた「今回のカード」の例です（詳細はカード面に従います）。

効果ざっくり
数値移動向いている方向へそのマス数
星同方向の次の星へ（ゴール越え可）
転倒伏せ。以後の移動は這って1マス
方向転換向きが逆になる
スワーブ左右のレーンへ。コース外は失格の原因に
衝突動いた側は無事、止まっていた側が転倒
復帰起き上がる／正面を向く（移動より先）
緑マルチ全員同時。衝突なし・ゴール不可
失格（DQ）転倒中の再転倒／衝突、コース外、短縮で埋まる、など

レース中、スマホ側で操作してマスコットを動かすことはありません。観戦と情報確認だけです。

7. 勝ち方

3レースすべての配当が終わったあと、所持金が最多のプレイヤーが勝利です。

8. 用語集

用語意味
マスコットレースする4体の駒。プレイヤー本人ではない
マ券勝ちマスコット投票券。着順で配当
サイドベット奇妙な展開（コースアウトなど）への賭け
セーフ / リスキー札の表裏。リスキーは高配当だが外れが痛いことも
スネークドラフト時計回り→逆順で取る方式
カード仕込み手札1枚を山に入れること
バーンスタート時に山の上3枚を捨てる
コース短縮山切れ後にコースが短くなる（旧称「コース崩壊」）
ラズパイ Enter会場の進行ボタン
全員揃い必要な操作を全員が終えた状態
使わない表記: 「馬券」「ノーマル」「イベント」（曖昧）、「払戻すべて×2」。
