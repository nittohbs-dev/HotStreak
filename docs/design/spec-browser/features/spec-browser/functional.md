## ビジネスルール

| BR-ID | ルール | 例外時の振る舞い |
|-------|--------|------------------|
| BR-sb-001 | 辺は設計表に書いた CLS/TBL/継承元だけ。推測で増やさない | 表に無い参照は無視 |
| BR-sb-002 | ノードの新規作成・辺の手編集はしない | UI に編集ハンドルを出さない |
| BR-sb-003 | ソース全文を snapshot に入れない | パスと ID ヒットのみ |
| BR-sb-004 | 設計ゼロでもキャンバスは開く | プレースホルダ1ノード |
| BR-sb-005 | 表示は常に設計プロジェクト1件のみ | 他プロジェクトのノード/辺は出さない |
| BR-sb-006 | 機能チェック0件は全機能表示 | — |
| BR-sb-007 | モバイルでアウトラインとインスペクタは同時に開かない | 後から開いた方だけ表示 |

## 要件

### REQ-sb-001: 設計スキーマ indexer

`design-doc` スキルが定めたファイル・表ヘッダ・ID だけを読み、`public/snapshot.json` を生成する。`vite build` の前に必ず実行する。テンプレに無い列は必須にしない。`docs/design/` 直下で `manifest.yaml` がある **すべての** `<projectId>` を索引する（ホワイトリストなし・名前非依存）。

ノード / 辺 / details の ID は `{projectId}:{kind}:{localId}` 形式とする。各ノードに `projectId` を載せる。辺種別は `feature→class` / `class→table` / `class→class`（`inherits`）とする。

### REQ-sb-002: ノードキャンバス

ダーク＋ドットグリッド上に Feature / ClassCommon / ClassFeature / Table を左から右へ配置し、曲線でつなぐ。継承辺は破線。パン・ズーム・層フィルタ・関連ハイライト。プロジェクト切替・機能マルチ選択・検索・ギャップのみと併用可能。

### REQ-sb-003: インスペクタ

選択ノードに応じて REQ・画面ワイヤー・API・責務・カラム・ソースパス・継承元/先を表示する。会話UIではない。関連 CLS / TBL / 機能 / 継承はクリックでノード遷移する。

### REQ-sb-004: GitHub Pages

`develop` への合併後、Actions が build → Pages 公開。Vite `base` は `/HotStreak/`（ローカルは `/`）。`main` は使わない。

### REQ-sb-005: ソース照合とギャップ

`frontend/` `backend/` `src/` を走査（除外: node_modules, target, .git, tools/spec-browser）。CLS-/TBL-/REQ- またはクラス名・テーブル名で照合。ヒットはチェックバッジ、未検出は警告。ギャップ件数をヘッダー表示（選択中プロジェクト分）。

### REQ-sb-006: プロジェクトスコープ（汎用）

ヘッダーで `snapshot.projects` から **常に1つだけ** 選択する（URL `?project=<projectId>`）。プロジェクト固有のハードコード分岐は作らない。

初期値: URL 指定 → なければ一覧の先頭 → 不正 ID なら先頭にフォールバック。

表示・アウトライン・ギャップ件数・検索対象は選択中プロジェクトのみ。他プロジェクトのノード/辺はキャンバスに出さない。新規に `docs/design/<新ID>/manifest.yaml` を置けば、ビューアコード変更なしで切替一覧に載る。

### REQ-sb-007: 左アウトライン

選択中プロジェクト内で、機能 → 配下クラス → 関連テーブルのツリーを出す。ノードクリックで選択・インスペクタ・キャンバスハイライト・`?node=` を更新する。機能行はチェックで複数選択（REQ-sb-008）。

### REQ-sb-008: 機能マルチ選択フィルタ

選択中の機能に属する Feature / Class / Table と、それらを結ぶ辺だけ表示する。0件選択時は **全機能表示**。共通クラスは、選択機能のいずれかが参照していれば表示する。複数機能選択時は、共有クラス経由の横断関係が見えること。

### REQ-sb-009: 検索・ギャップのみ

ラベル / CLS- / TBL- / 機能ID の部分一致でアウトラインとキャンバスを絞る。「ギャップのみ」で `implemented === false` に限定する。

### REQ-sb-010: 継承辺（任意）

クラス表の任意列 **`継承元`**（値は `CLS-…`、無し可）だけから Class→Class 辺（種別 `inherits`、破線）を作る。列欠落は継承なしと同じ。インスペクタに継承元/先を出し、クリックでジャンプする。

### REQ-sb-011: モバイル（狭幅）最適化

ブレークポイント: ビューポート幅 **≤768px** をモバイルとする。

- デスクトップ: 三ペイン（アウトライン | キャンバス | インスペクタ）
- モバイル: キャンバス全幅を主面。アウトライン／インスペクタはドロワーまたはボトムシート（同時に両方は開かない）
- ヘッダーは折りたたみ可能。プロジェクト切替・検索・ギャップは到達可能
- タッチ: パン／ズームは React Flow、ノードはタップで選択。コントロール余白は指向け
- 空状態・エラーも狭幅で読めること
